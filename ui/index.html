Load a simulation bundle

  1. Run the reference and the three policies, and bundle them: python scripts/run_all.py
  2. (Or by hand: scripts/run_sim.py --policy … for static, abc_cost_test, family_grouping, racksmart, then scripts/export_ui.py.)
  3. Choose data/processed/ui/bundle_<start>_<end>.json, or drop it here.

The file is read in this browser only. Nothing is uploaded or saved.
